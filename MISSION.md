# factory-sample-services (Backend): mission

## What it is

A small Go HTTP API that shortens URLs. Links live in PostgreSQL and visit counters live in Redis. The integration tests need both services running for real, so this repository exercises the Software Factory's Go runtime and its test services (PostgreSQL and Redis containers beside the sandbox).
